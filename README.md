# Homebrew tap for VideoGlance

[VideoGlance](https://videoglance.app/) adds Quick Look previews and Finder
thumbnails for MKV, WebM and other videos on Mac. It is free.

This tap holds the VideoGlance cask. It installs the disk image notarized by
Apple and published in the
[website's releases](https://github.com/Kwadz/videoglance-site/releases),
with no Homebrew dependency. Requirements and installation steps are on the
[download page](https://videoglance.app/en/download.html).

Report a problem in the
[website's issues](https://github.com/Kwadz/videoglance-site/issues).
